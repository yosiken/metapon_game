# METAPON（メタポン）

海の中で遊ぶ、浮上型アクションパズル。スマートフォンのブラウザ向け。**6列 × 12行、両手持ち専用。**

上から瓦礫が降り積もり、海底のあなたを埋めていく。
同じ色を3つ揃えると**凍って氷になり**、浮力で上の瓦礫ごと水面へ運び去る。
ただし**氷は融ける。** 最初のひとかたまりだけでは、まず水面まで届かない。

浮上中の塊も、沈んでいく塊も、まだ操作できる。
昇っている最中に次のマッチを作って氷を継ぎ足し、連鎖を伸ばして水面まで押し切る——
**「マッチさせて終わり」ではなく「マッチさせてからが本番」。**

指は2本、同時に浮く氷塊は最大3本。どれを伸ばしてどれを沈めるかを、毎秒選び続けるゲーム。
