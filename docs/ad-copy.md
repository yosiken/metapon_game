## キャッチコピー（候補）

1. **氷が融けきる前に、次を凍らせろ。**
2. **凍らせて、終わりじゃない。**
3. **マッチは、始まりでしかない。**
4. **息を止めて、浮かび上がれ。**
5. **3つ揃えたら、本番が始まる。**

→ 一番押しているのは **1**（`pitch.md` の結び）。以下もこれをメインに統一。

## ストア掲載・紹介文（本文）

### 短縮版（SNSプロフィール・広告見出し用、100字程度）

海底に埋もれるその前に、ブロックを凍らせて浮き上がれ。
でも氷は融ける。浮いている最中に、次を繋がなきゃ届かない。
「マッチさせて終わり」じゃない、マッチさせてからが本番のパズル。

### 標準版（アプリストア詳細ページ用）

```
海の底に、あなたはいる。

上から絶え間なく降り積もる瓦礫。
放っておけば、いずれ埋もれて終わる。

同じ色を3つ揃えると、ブロックは凍って氷になる。
氷は浮く。だから、上に乗った瓦礫ごと水面へ運び去ってくれる。

――でも、ひとかたまりだけでは、まず届かない。
氷は融けるから。

だから、浮き上がっている「最中」に、次のマッチを仕込む。
氷を継ぎ足し、連鎖を伸ばし、融けきる前に押し切る。

これは「マッチさせて終わり」のパズルじゃない。
「マッチさせてから」が本番のパズルだ。

━━━━━━━━━━━━━━━━━━━

■ 指は2本、氷塊は最大3本
同時に浮かぶ塊は最大3つ。でも指は2本しかない。
どれを伸ばし、どれを見捨てるか——その判断が毎秒訪れる。

■ 盤面が、勝手にリズムを刻む
氷は音楽の拍に合わせてしか融けない。
盤面じゅうの氷が拍の頭で一斉に砕け、その音がそのままパーカッションになる。

■ 融ける寸前を狙え
ギリギリまで待って繋げば、スコアも浮力も跳ね上がる。
「早く繋ぐほど安全」だったはずの連鎖に、待つ理由が生まれる。

■ 操作は、指1本の縦ドラッグだけ
ブロックを上下に動かす。それだけ。
覚えることはひとつ。上達に終わりはない。

━━━━━━━━━━━━━━━━━━━

スマホのブラウザで、いますぐ。インストール不要。
```

### 長さ違いパーツ（ストアの文字数制限に合わせて切り出す用）

## 用語メモ（コピーを書くときの表記統一）

| 用語 | 表記 |
| --- | --- |
| タイトル | METAPON（メタポン）※初出のみ両方併記、以降は METAPON |
| 凍る/マッチ | 「凍らせる」「結氷」はゲーム内用語。対外文では基本「凍らせる」 |
| 打ち上がる動作 | 「浮上する」「浮かび上がる」「押し切る」を場面で使い分け |
| ジャンル | 「海中アクションパズル」（「落ち物パズル」は経験者向けの文脈でのみ使用） |

## 使用ガイド

- **世界観から入るか、システムから入るか**で刺さる層が変わる。
  カジュアル層向けの告知は「海底・凍る・浮く」の情景から（世界観訴求）。
  パズル経験者向けは「指2本 vs 氷塊3本」「拍量子化」などシステムの独自性から（一撃/技術トリビア寄せ）。
- キャッチコピーは `pitch.md` の結びと統一してあるので、企画書とプレイヤー向け告知で言っていることがズレない。
- ストア文の「■」見出し3点は `pitch.md` の「4つの特徴」から抜粋・要約している。
  仕様が変わったら両方直すこと。
