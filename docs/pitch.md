# METAPON（メタポン）— 企画概要

スマートフォンのブラウザで遊ぶ、海中が舞台のアクションパズル。1人用。縦画面。

---

## どんなゲームか

海底にいる。上から瓦礫が降り積もり、埋もれたら終わり。

同じ色を3つ揃えると、そのブロックは**凍って氷になる**。
氷は浮くから、**上に乗った瓦礫ごと水面へ運び去る**。

ただし**氷は融ける。** ひとかたまりでは、まず水面まで届かない。

だから——**浮き上がっている最中に、次のマッチを作る。**
氷を継ぎ足し、連鎖を伸ばし、融けきる前に水面まで押し切る。

操作は**縦ドラッグだけ**。列の中でブロックを上下に動かす、それしかない。

---

## 何を受け継ぎ、何を変えたか

| 元ネタ | 受け継ぐもの | 変えたこと |
| --- | --- | --- |
| **メテオス** | 縦ドラッグ、3マッチ、浮力 vs 重量の物理 | 横10列 → **縦画面の6列**。打ち上げを「たまの爽快演出」から**常時の主戦場**へ |
| **パネルでポン** | アクティブ連鎖（動いている最中に次を仕込む） | 連鎖の舞台を平面の盤面から**浮上中の塊の内部**へ移した |

**「マッチさせて終わり」ではなく、「マッチさせてからが本番」。**

---

# 4つの特徴

## 1. 単発では、届かない

浮力は凍らせた数に比例し、重量は塊全体に比例する。
つまり**下の方で凍らせるほど、上に載った重量を背負う。**

| 状況 | 加速度 | 結果 |
| --- | --- | --- |
| 最上部で3マッチ | +8.0 | 即、水面へ |
| 上に5個ある状態で3マッチ | **−2.0** | 3セル浮いて沈む |
| 上に5個 + **浮上中に2連鎖目** | **+5.0** | 加速して水面へ |

「浮かせてから連鎖を繋いで押し切る」が**クリアの標準手順**になるよう数値を組んである。
偶然訪れる爽快感ではなく、**毎回そうしないと勝てない。**

## 2. 指は2本、氷塊は3本

6列の盤面では、最大3つの氷塊が同時に浮いている。**しかし指は2本しかない。**

どれを伸ばし、どれを沈めるか——この取捨選択が毎秒発生する。
これが本作の上達曲線の中心であり、**6列でしか成立しない**。
4列では塊が実質1本になり、判断そのものが生まれなかった。

## 3. 盤面が、自分でリズムを刻む

**氷は拍の上でしか融けない。** 融解タイミングを拍グリッドに量子化してある。

- 盤面じゅうの氷が拍の頭に揃って砕け、融解音が**そのままパーカッションになる**
- 繋ぐべき瞬間が**耳で分かる**。氷の亀裂の本数も、同じグリッドで段階的に増えていく
- **拍の直後に凍らせた氷は長持ちする**——リズムに乗る動機が、加点ではなく**物理から生まれる**
- ただし、拍を無視しても成立する。**ゲートではなく報酬**

そのうえで**際結氷（きわけっぴょう）**——融ける最後の一瞬で次を繋ぐと、スコアと浮力が伸びる。
これにより「早く繋ぐほど安全」だった連鎖に、**待つ理由**が生まれた。

## 4. 海中という設定が、ルールを説明する

単なる見た目の話ではない。**恣意的だった数値に、物理的な根拠がつく。**

| ルール | 海中での説明 |
| --- | --- |
| 速度に上限がある | **水の抵抗**による終端速度 |
| 効果が時間で切れる | **氷が融ける**。しかも**見た目で残り時間が分かる** |
| 凍った瞬間にひと押し進む | **凍結時の体積膨張** |
| 氷は掴めず、通り抜けられない | **凍りついている** |
| ステージごとの難易度差 | **水温と塩分**。同じ水温が、浮きやすさと融ける速さを同時に動かす |

そして「凍る瞬間に溶存気体が気泡として析出し、氷に抱き込まれる」——この一行の設定が、
**気泡の演出と「氷は時間で浮力を失う」というルールを、同時に説明する。**

## この企画の一行

# 「氷が融けきる前に、次を凍らせろ。」

操作は縦ドラッグだけ。動詞はひとつ。
そこに**物理と、リズムと、取捨選択**が、すべて乗っている。
