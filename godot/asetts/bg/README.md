# 背景素材

| ファイル | 用途 |
| --- | --- |
| `underwater.png` | ゲーム中の背景。810x1440（仮想解像度 540x960 の1.5倍） |

## 作り方

提供された正方形に近い原画から、`tools/make_bg.py` で切り出す。

```
python3 tools/make_bg.py <原画> asetts/bg/underwater.png
```

- **高さいっぱいを使って幅を 9:16 に詰める**。原画は光条の収束点が
  ほぼ中央（上端の明度重心 x=662 / 幅1392、中心は696）にあるので、
  中央切り出しでそのまま画面上部の水面と揃う
- 彩度 0.68 / 明度 0.58 / ぼかし 1.4px。原画は宝石が密に散った高コントラストの
  絵で、そのまま敷くとブロックと同じ「小さくて色の濃い塊」として読めてしまう
  （仕様書 §11.2）。背景へ退かせるための加工で、見栄えの調整ではない

## インポート設定

`compress/mode=1`（非可逆 WebP）/ `lossy_quality=0.85` にしてある。
可逆だと `.ctex` が 757KB あり、モバイル回線での初回読み込みに効く。
非可逆で **71KB**（約 1/10）。写真なので劣化は視認できない。

## 実行時に重ねているもの

背景は敷くだけでは済まない。`scripts/main.gd` の `_draw_water()` が上から重ねる。

| 重ねるもの | 理由 |
| --- | --- |
| 奥行きの階調（海底ほど濃い幕 0.74 → 水面 0.08） | 水面までの距離を伝える信号（§3.1） |
| 危険域の赤染め | あと何段で埋没かの信号（§4.5） |
| 画面上端・下端の暗幕 | 写真で一番明るいのが水面付近＝HUD の位置。落とさないと文字が読めない |
| 盤面の矩形だけの暗幕（`_draw_board_frame`） | 幕の内側が操作対象、という読み分けを作る（§11.2） |

階調と赤染めは**装飾ではなく信号**なので、画像に焼き込まず必ず実行時に描く。
