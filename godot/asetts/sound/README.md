# 音源

`scripts/view/game_audio.gd` の `BGM_PATH` と `SE` がこのフォルダを読む。
**ファイルが無いイベントは黙って無音になる**ので、一部だけ置いても動く。

| イベント | 音 | ピッチ | 備考 |
| --- | --- | --- | --- |
| 掴む | `click.wav` | 1.00 | |
| 結氷 | `Freezing.wav` | 1.00 | **連鎖数に応じてメジャースケールで音階が上がる**（§11.1） |

# 実測と、コード側で入れている補正

## 1. 先頭の無音 42〜44ms（★重要）

| ファイル | 全長 | 先頭無音 | 実音長 | 末尾無音 |
| --- | --- | --- | --- | --- |
| `Freezing.wav` | 1130 ms | **43 ms** | 889 ms | 198 ms |
| `Melting.wav` | 860 ms | **42 ms** | 616 ms | 202 ms |
| `click.wav` | 705 ms | **42 ms** | 500 ms | 163 ms |
| `floatup.wav` | 1360 ms | **44 ms** | 1037 ms | 280 ms |

BPM128 の16分音符は **117 ms**。42 ms はその **36%** にあたる。
補正しないと、拍グリッド上で鳴るはずの打楽器が**常に拍の後ろにずれて**鳴り、
「盤面が音楽を刻む」（§4.6）が成立しない。

**コード側の対応**: `SE` の `lead` に実測値を入れ、`play(lead)` で無音を飛ばして再生している。

> **音源側で先頭を詰めてもらえるのが本筋。** 詰めたら `lead` を 0 にする。

## 2. SE が長すぎる

実音長が 500〜1037 ms ある。16分音符（117 ms）で連打される融解音としては長い。
Lv5 以降は 117 ms ごとに融解しうるため、そのままでは音が団子になる。

**コード側の対応**: `SE` の `max_dur` でフェードアウトさせている（融解は 220 ms）。

> **融解音は 200 ms 以下・アタックの立った短い音が望ましい。**
> 残響が長いと拍が濁る。ここは §4.6 の成否に直結する。

## 3. ★BGM のテンポが 128 ではない可能性が高い

`tools/analyze_bgm.py` で ogg の波形を直接解析した結果:

```
Breathing Spaces.ogg   sr=48000  長さ 229.8535s
先頭無音 126.9 ms   末尾無音 2287.1 ms   実音区間 227.4395s

 順位      BPM    位相(ms)   オンセット強度
    1   102.50        70        0.847
    2    82.00       655        0.506
    3   164.00       290        0.261

実測テンポ : 102.51 BPM（先頭オフセット 84 ms）強度 1.103
想定 128.00 BPM                              強度 0.144
=> 実測テンポのほうが 7.7 倍強い
```

低域（キック）のスペクトルフラックスに対して、BPM 候補と拍位相を総当たりし、
拍の位置にオンセットがどれだけ集中するかで採点している。
**102.5 BPM が 128 BPM の 7.7 倍のスコア**で、差は明確。

102.5 × 1.25 = 128.1 なので、128 のグリッドは 4拍に1回だけ実際の拍と一致する。
これが 128 がゼロではない弱いスコアを出している理由で、**部分一致にすぎない**。

> **未解決。** `cfg.gd` の `BPM` / `TICKS` は現在 128 のまま。
> 102.5 が正しい場合、`BPM = 102.5` / ティックレート **205 Hz**（＝102.5×2、1拍=120ティック）に変更する。
> テンポの出どころ（生成時の設定 / DAW の表示）を確認してから直す。

## 4. ogg 化で解決しなかったこと

ogg の長さは mp3 と**完全に同一の 229.8535s**だった。
つまり小節とのズレは mp3 のパディングが原因ではなく、**曲そのものが小節の整数倍でない**。

- 実測 102.51 BPM で 98.18 小節（0.176 小節＝412 ms のズレ）
- 末尾に 2.29 秒の無音がある

ループを拍に乗せるには `game_audio.gd` の `BGM_LOOP_SEC` に
小節の整数倍の秒数を入れる。テンポ確定後に設定する。

ogg 化の効果は**ループ継ぎ目の隙間が無くなったこと**で、これは有効。

## 測り直す

```
pip install numpy soundfile
python godot/tools/analyze_bgm.py "godot/asetts/sound/bgm/Breathing Spaces.ogg" --assume-bpm 128
```

## テンポを変える場合

BGM は BPM 128。sim のティックレートも 128Hz に揃えてある（§4.6.3）。
差し替えでテンポが変わる場合は `scripts/sim/cfg.gd` の
`BPM` と `TICKS` の**両方**を新しいテンポの値にすること（この2つは常に同じ値）。

## Godot 側から測る

```
godot --headless --path godot --script res://tests/audio_check.gd
```
