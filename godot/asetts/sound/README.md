# 音源

`scripts/view/game_audio.gd` の `BGM_PATH` と `SE` が、このフォルダのファイルを読む。
**ファイルが無いイベントは黙って無音になる**ので、一部だけ置いても動く。

```
asetts/sound/
  bgm/Breathing Spaces.mp3   BPM 128
  se/Freezing.wav            結氷。連鎖数ぶん音階が上がる
  se/Melting.wav             融解。★ゲームのパーカッションの実体（§4.6）
  se/click.wav               掴む / 際窓のチック
  se/floatup.wav             水面到達
```

## イベントへの割り当て

| イベント | 使っている音 | 備考 |
| --- | --- | --- |
| 掴む | `click.wav` | −9 dB |
| 結氷 | `Freezing.wav` | **連鎖数に応じてメジャースケールで音階が上がる**（§11.1） |
| 際結氷（§5.8） | `Freezing.wav` を1オクターブ上 | **専用音が欲しい**。結氷と区別がつく鋭い音 |
| 融解（§4.6） | `Melting.wav` | 拍グリッド上でしか鳴らない＝打楽器 |
| 水面到達 | `floatup.wav` | |
| 沈降して着地 | `Melting.wav` を 0.62倍のピッチ | **専用音が欲しい**。鈍く重い音 |
| 際窓のチック（§6.4.1） | `click.wav` を 2.2倍のピッチ | −16 dB |

**専用音が欲しいのは「際結氷」と「着地」の2つ**。
いまは既存音のピッチを振って代用しているので、用意できたら
`game_audio.gd` の `SE` の該当行の `path` を差し替えるだけでよい。

## BGM の形式について

いま mp3。**最終的には ogg への変換を勧める。**

mp3 はエンコーダの仕様上、先頭と末尾に無音のパディングが入る。
ループ再生すると継ぎ目に数十ミリ秒の隙間ができ、**拍がずれる**。
本作は融解タイミングを拍に量子化している（§4.6）ので、この隙間は設計に直接効く。

コード側では BGM の再生位置を sim 時刻に追従させ（`sync_bgm`）、
ズレが 80ms を超えたらシークして直すため破綻はしないが、継ぎ目は聞こえる。
ogg なら隙間なくループできる。

## テンポを変える場合

BGM は BPM 128。sim のティックレートも 128Hz に揃えてある（§4.6.3）。
差し替えでテンポが変わる場合は `scripts/sim/cfg.gd` の
`BPM` と `TICKS` の**両方**を新しいテンポの値にすること（この2つは常に同じ値）。
