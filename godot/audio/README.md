# 音源の置き場

`scripts/view/game_audio.gd` が以下のパスを読む。
**ファイルが無い場合は黙ってスキップする**ので、一部だけ置いても動く。
ファイル名が違う場合は `game_audio.gd` 冒頭の `BGM_PATH` / `SE_PATHS` を直す。

```
audio/
  bgm/
    main.ogg        BGM。ループ用に .ogg 推奨（インポート設定で Loop を有効に）
  se/
    grab.wav        ブロックを掴む
    freeze.wav      結氷。連鎖数に応じて音階が上がる（無加工の単音を入れること）
    kiwa.wav        際結氷（§5.8）。freeze とは別系統の高く鋭い音
    melt.wav        融解。★これがゲームのパーカッションの実体（§4.6）
    surface.wav     水面到達
    land.wav        沈降して着地
    tick.wav        際窓のグリッド頭で鳴る小さなチック（§6.4.1）
```

## freeze.wav について

`play_freeze()` が `pitch_scale` で音階を付ける（メジャースケールで連鎖数ぶん上昇）。
そのため **freeze.wav は単音・短め・ピッチが明確な音**にすること。
和音やノイズ主体の音だとピッチシフトが破綻する。

## melt.wav について

融解は拍グリッドの上でしか起きない（§4.6）。つまりこの音がそのまま
BGM に乗るパーカッションになる。**短くアタックの立った音**にすること。
残響が長いと拍が濁る。

## BPM

BGM は **BPM 128**。sim のティックレートも 128Hz に合わせてあるので、
グリッド線（8分＝30ティック、16分＝15ティック）は必ず拍に一致する。
BGM を差し替えてテンポが変わる場合は `scripts/sim/cfg.gd` の
`BPM` と `TICKS` の両方を新しいテンポの値に変えること（両者は常に同じ値）。
